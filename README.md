# TT-Neutron-Transport

> **Work in progress.** This is an active research code: the interfaces, file layout and results may change
> without notice, and some parts are incomplete or not yet in the repository.

Tensor-train (TT) solvers for the neutron transport equation, built on
[`torchtt`](https://github.com/ion-g-ion/torchTT). The phase space (space × angle × energy group × time) is
discretised and solved as a single linear system in TT format with AMEn.

## Layout

```
slab_1d_spatial_domain/   1D slab geometry: package tt_transport (SlabTransportModel), studies
                          (convergence, pure absorber, infinite medium, Monte Carlo comparisons, ansatz,
                          preconditioning), docs and slides. See its README.
box_3d_spatial_domain/    3D box geometry: package tt_transport_box (BoxTransport), studies
                          (infinite medium, beams, ansatz, preconditioning), theory and docs.
```

Each folder is its own installable package:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e slab_1d_spatial_domain
pip install -e box_3d_spatial_domain
```

Requires Python ≥ 3.10 with `numpy`, `scipy`, `matplotlib`, `torch` and `torchtt`.

Large outputs (solution tensors `*.pt`, dense fields, movies) are not tracked and are regenerated by the study
scripts; small reference data (Monte Carlo fluxes, multigroup cross sections) is kept in the repository.
